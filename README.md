# Go Booking App 🧾

This is a terminal-based ticket booking application written in Go.  
Users can book tickets for the Go Conference, and the system handles input validation, stores booking info, and tracks remaining tickets.

---

## 🚀 Features

- Collects user details (name, email, ticket count)
- Validates user input
- Tracks remaining tickets
- Stores booking info using maps and slices
- Displays list of first names of users who booked

---

## 📦 Project Structure

```bash
.
├── helper/           # contains validation logic
├── main.go           # entry point if you prefer this over test.go
├── test.go           # contains main booking loop and functions
└── go.mod            # Go module file
```
